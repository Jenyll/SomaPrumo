Design System (inicial)
----------------------

Tokens e estilos
- Tipografia: Cormorant Garamond (display) + Manrope (UI) — conforme ADR-007
- Escalas de cores: definir tokens para primary, secondary, success, warning, danger, neutral
- Espaçamentos e radii: tokens para gap, padding, border-radius

Componentes
- Atômicos: Button, Input, Select, Checkbox, Modal, Tooltip
- Moleculares: Form, Table, Card

Acessibilidade
- Seguir WCAG AA como meta mínima
- Componentes com foco e roles ARIA compatíveis

Theming
- Suporte a tema claro/escuro via CSS variables
